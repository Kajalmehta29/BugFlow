# BugFlow Frontend

This directory contains the React + Vite frontend SPA for BugFlow.

## 🚀 Getting Started

To run the frontend service:
1. Ensure the backend API is running at the address configured in your `.env` (or default `http://localhost:8080/api/v1`).
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the local Vite development server.

For full project architecture, environment variable config, and running databases via docker-compose, please refer to the main [Root README.md](../README.md).
